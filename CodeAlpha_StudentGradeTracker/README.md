# Student Grade Tracker

## Description
A Java console-based application that helps manage student academic records.

## Features
- Add Student
- Display Student Records
- Calculate Average Marks
- Find Highest Marks
- Find Lowest Marks
- Input Validation

## Technologies Used
- Java
- IntelliJ IDEA
- OOP
- ArrayList

## How to Run
1. Open project in IntelliJ IDEA
2. Run Main.java
3. Follow the menu options
