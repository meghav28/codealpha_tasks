# 📈 Stock Trading Platform

A Java console-based Stock Trading Platform developed as part of the **CodeAlpha Java Programming Internship**. This application simulates basic stock market operations, allowing users to buy and sell stocks, manage their portfolio, and track their available balance.

---

## 🚀 Features

- 📊 View available stocks with current prices
- 💰 Initial virtual balance of ₹100000
- 🛒 Buy stocks
- 💸 Sell stocks
- 📂 View portfolio
- 💳 Automatic balance updates after every transaction
- ✅ Input validation for insufficient balance
- 🖥️ Interactive menu-driven console interface

---

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Run `Main.java`.
4. Choose options from the menu to:
    - View Stocks
    - Buy Stocks
    - Sell Stocks
    - View Portfolio
    - Exit
