# 🏨 Hotel Reservation System

A Java console-based Hotel Reservation System developed as part of the **CodeAlpha Java Programming Internship**. This application allows users to view available rooms, book rooms, cancel bookings, simulate payments, and manage hotel reservations through an interactive menu-driven interface.

---

## 🚀 Features

- 🏨 View available hotel rooms
- 🛏️ Book a room
- ❌ Cancel an existing booking
- 📋 View all bookings
- 💳 Payment simulation with room-wise pricing
- ✅ Prevent duplicate room bookings
- 📊 Display room availability status
- 🖥️ Interactive menu-driven console application

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Run `Main.java`.
4. Select options from the menu to:
    - View Rooms
    - Book Room
    - Cancel Booking
    - View Bookings
    - Exit

## 💳 Payment Simulation

The system calculates the booking amount automatically based on the selected room type.

| Room Type | Amount (₹) |
|-----------|-----------:|
| Standard | 2000 |
| Deluxe | 3500 |
| Suite | 5000 |

After a successful booking, the application generates a simple payment confirmation.
